How do children acquire language?

### Why language acquisition?
Babies are amazing at learning language.

Pronunciation **phonology**
Know how to put words together **syntax**
**Pragmatics** identify the right interpretation in context

Most linguistics systems are already known by age 4.
- Children seem to be extracting patterns mostly by hearing examples of what is allowed in the language.
- Often many ways to **generalize beyond the input.**

**Induction problems** are justifying predictions of unobservable things from past behavior.

*Why are you doing it*. Once you know this you can answer the question you are trying to answer.

### Making the components explicit
Humans don't necessarily specify all the details necessary
- Learning linguistic structures from "triggers"
The trigger for wh-movement is seeing  wh-word in a position different from where it's understood
Children need to:
- know a certain word
- recognize a wh-word
- remember the fronted wh-word
- ignore utterances 

### The importance of Theory
"...you need to first have a theory about how acquisition works. Then, the model can be used to
(1) make all components of that acquisition theory *explicit*,
(2) evaluate whether it actually works, and
(3) determine precisely what makes it work (or not work)." - Pearl in press

### Evaluating whether the theory works and determining what makes it work
"Once an acquisition theory is specified enough to implement in a computational model, we can then evaluate it by comparing the predictions it generates against the empirical data available from children." - Pearl

*Two basic outcomes*: 
- the model predictions match children's data
- the model predictions *don't match* children's data

This is an existence proof that the acquistion theory, as implemented in the model, is a way acquistion *could* proceed.

The model predictions *don't* match children's data

If the model's predictions don't match children's behavior without these, we can say they're *necessary components* of the learning strategies this theory describes and we can explay *why*

### Modeling as a useful tool
Modeling can be used as a tool for both **developing** and **refining** acquisition theories.
